RIVINGTON MARX — WEBSITE REDESIGN STUDY ONE
============================================

Direction: Cinematic Album
Format: Desktop-only interactive HTML prototype

HOW TO VIEW
-----------
1. Keep this study folder beside the shared root assets folder.
2. Open the project hub or this index.html in Chrome, Safari, Edge, or Firefox.
3. View at a desktop browser width of at least 1280px for the intended composition.
4. An internet connection is only required if the final "Begin a project" link is opened.

INTERACTIONS INCLUDED
---------------------
- Full-screen navigation overlay
- Scroll-driven horizontal project album
- Hover image scaling and visual project index
- Click-to-open project image lightbox
- Scroll reveals and photographic parallax
- Reduced-motion fallback

SCOPE NOTES
-----------
- This is Study One only, intended for creative-direction review.
- The mobile version has deliberately not been designed yet.
- Project labels and supporting copy are direction-level content and can be refined after approval.
- Every photograph in the prototype comes from the supplied Client Images folder.
