RIVINGTON MARX — WEBSITE REDESIGN STUDY 03
The Horizontal Room / Desktop Interactive Concept

HOW TO VIEW
Open index.html in a modern desktop browser. Use a window at least 1280px wide
for the intended presentation. No installation, internet connection or build
step is required.

CONCEPT
Study Three replaces the conventional vertical homepage with a controlled,
full-screen presentation. A fixed editorial rail holds the story and controls;
photography moves horizontally through a large image stage. This is deliberately
different from the cinematic vertical pacing of Study One and the long-form
editorial layout of Study Two.

PRIMARY INTERACTIONS
- Horizontal project reel with visible next-image cue
- Circular previous/next controls and animated progress line
- Direct drag navigation and keyboard arrow support
- Smooth section transitions between Work, Point of View, Approach, Studio and Contact
- Full-screen project index with focus/hover image preview
- Click-to-expand project presentation layer
- Reduced-motion alternative

TYPOGRAPHY
The display system uses a Palatino-style old-style serif rather than the
Bodoni/Didot character used in the earlier studies. Navigation and metadata use
an Avenir-style sans serif with system fallbacks.

IMAGE USE
Every photograph in this prototype comes from the Rivington Marx Client Images
folder. No stock or AI-generated photography has been used.

SCOPE NOTE
This is intentionally a desktop-only study. Screens below 980px display a
desktop-study notice. Mobile design will follow only after a direction is approved.

Project labels and short editorial copy are concept presentation content and
should be reviewed against final client-approved project names, locations and
brand messaging before production.
