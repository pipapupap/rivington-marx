RIVINGTON MARX — WEBSITE REDESIGN STUDY 02
Editorial House / Desktop Interactive Concept

HOW TO VIEW
Open index.html in a modern desktop browser. For the intended presentation, use a
window at least 1280px wide and allow the page to run its built-in interactions.
No installation, internet connection, or build step is required.

CONCEPT
Study Two presents Rivington Marx as a collectible design journal. The direction
uses asymmetric editorial composition, overscale typography, portrait-led project
stories, considered whitespace, restrained motion, and confident colour.

INTERACTIONS
- Scroll progress and subtle image parallax
- Editorial story index with hover/focus image switching
- Scroll-triggered chapter reveals
- Click-to-expand project photography
- Draggable horizontal detail collection
- Full-screen navigation index
- Animated service rows and project links

IMAGE USE
Every photograph in this mockup was supplied in the Rivington Marx client image
folder. No stock photography or AI-generated imagery has been used.

SCOPE NOTE
This is intentionally a desktop-only design study. Screens below 980px display a
desktop-study notice; a mobile design has not been created at this stage.

The project labels and editorial copy are concept presentation content and should
be reviewed against final client-approved project names and brand messaging before
production.
