RIVINGTON MARX — STUDY 05
The Light Editorial Gallery

Desktop homepage design study. Best viewed at 1280px or wider.

Open index.html, or serve the outputs folder and visit /study-5/.
Keep this folder alongside the shared assets folder. All client photographs
are referenced from ../assets/; no image copies have been created.

Interactions: featured-image arrows, collection filters, vertically scrolling
collection photographs, three horizontal text chapters per collection,
thumbnail selection, image enlargement, keyboard arrows and Escape,
four horizontal editorial image/text panels, a vertical studio image column,
expanded navigation, approach accordions, section navigation, and email links.
Horizontal stories support left/right arrows, trackpad scrolling, or the mouse
wheel while pointing inside the story. At either end, wheel input returns to
normal page scrolling. Photographs scroll up/down independently of the text.

Typography: Newsreader and Manrope through Google Fonts, with local fallbacks.
Project groupings and collection titles are illustrative editorial labels.
The contact links use the studio's published email and phone number.

This is an HTML prototype, with no form backend or analytics.
This folder is Study 5 in the current five-study collection.
